# PRD — 히어로 챌린지 게임 포털 (Design Prototype)

## 1. 개요

`screenshot.png`와 동일한 느낌의 어린이용 게임 포털 SPA를 만든다.
**디자인 프로토타입**이며, 백엔드/데이터베이스 없이 프론트엔드 인터랙션만 구현한다.

- 스택: **Vite + React** (JavaScript), 순수 CSS
- 데이터: 컴포넌트 내 정적 목(mock) 데이터
- 대상 화면: 데스크톱/태블릿 가로 화면 우선 (1280px 기준), 좁은 화면에서는 그리드 축소

## 2. 프로젝트 구조 (Monorepo)

이 프로젝트는 향후 서버까지 포함하는 **monorepo**로 확장한다.
npm workspaces 기반으로 시작한다:

```
icecream/
├── package.json          # 루트 — workspaces: ["apps/*", "packages/*"]
├── PRD.md
├── screenshot.png
└── apps/
    └── web/              # 이번에 만드는 Vite + React SPA
        # (향후) apps/server, packages/shared 등 추가 예정
```

## 3. 목표

1. 스크린샷의 비주얼(다크 퍼플·블루 게임 테마, 네온 글로우, 카드 그리드)을 충실히 재현한다.
2. 정적 이미지가 아닌 **인터랙티브**한 앱으로 만든다 — 메뉴 전환, 즐겨찾기, 호버 효과가 동작한다.
3. DB·API 없이 새로고침하면 초기 상태로 돌아가도 무방하다.

## 4. 화면 구성

### 4.1 레이아웃

- **좌측 사이드바**
  - 상단: "히어로 챌린지" 로고 뱃지 (AI 키성장 + 바른자세 교실)
  - 메뉴 6개: **월요일 ~ 토요일** (요일별 게임 편성)
  - 활성 메뉴는 네온 테두리 + 글로우로 강조
  - **모바일(≤860px)**: 사이드바는 숨겨지고 햄버거 버튼으로 대체 —
    클릭 시 왼쪽에서 슬라이드되는 애니메이션 드로어 + 배경 딤 표시
- **우측 메인 영역**
  - 페이지 타이틀 **"늘봄교육"** (노란색·주황 그라데이션 대형 타이포) + 요일별 부제 문구
  - 배경: 짙은 남보라 그라데이션 + 도트 패턴 장식

### 4.2 요일 페이지 (핵심 화면)

- 상단 **히어로 배너 1개**: 그 요일의 추천 게임 —
  그라데이션 배경, 추천 게임 이름·설명·능력 태그, "지금 시작하기" 버튼, 우측 이모지 아트(플로팅 애니메이션)
- 아래 **"오늘의 게임" 카드 4개** 그리드 (좁은 화면에서 2열 → 1열)
- 게임 풀 8종(멈춰! 얼음땡, 기억력 카드, 폭탄 피하기, 두더지를 잡아라, 청기 백기, 바이러스 잡기, 푸드캐처, 단체 줄넘기)을 요일별로 순환 편성
- 카드 구성:
  - 썸네일: 실사 이미지 대신 게임별 그라데이션 + 이모지 일러스트 (디자인 목업)
  - 우상단 별(즐겨찾기) 뱃지 — 클릭으로 토글
  - 게임 이름 + 능력 태그 1~2개 (순발력, 집중력, 기억력, 유산소, 협동력)
- 섹션 헤더 우측에 능력 태그 필터 칩 — 선택한 능력의 게임만 표시

## 5. 인터랙션 요구사항 요약

| 동작 | 결과 |
|---|---|
| 사이드바 요일 클릭 | 해당 요일 편성으로 전환, 활성 스타일 이동 |
| 햄버거 버튼 (모바일) | 사이드바 드로어 슬라이드 인/아웃, 배경 클릭·✕·요일 선택으로 닫힘 |
| 히어로 "지금 시작하기" | 추천 게임 상세 모달 열림 |
| 카드의 별 클릭 | 즐겨찾기 토글 |
| 태그 필터 클릭 | 해당 능력 게임만 필터링, 다시 클릭하면 해제 |
| 카드 클릭 | 상세 모달 열림, 배경 클릭/닫기 버튼으로 닫힘 |
| 카드/버튼 호버 | 부양 + 글로우 효과 |

## 6. 비주얼 가이드

- 배경: `#1a1040` ~ `#2a1a6e` 계열 남보라 그라데이션
- 포인트: 네온 블루 `#4dd8ff`, 퍼플 `#8b5cf6`, 노랑 `#ffd83d` (타이틀·별)
- 카드: 보라 그라데이션 테두리, 둥근 모서리(16px+), 진한 그림자
- 타이포: 둥글고 두꺼운 한글 폰트 (Jua 웹폰트), 타이틀은 그라데이션 텍스트
- 전체적으로 "모바일 게임 런처" 느낌의 밝고 통통 튀는 무드

## 7. 범위 제외 (Non-Goals)

- 실제 게임 플레이 구현
- 로그인/회원, 서버 통신, 데이터 영속화 (localStorage 포함)
- 라우팅 라이브러리 (state 기반 페이지 전환으로 충분)
- 모바일 세로 대응 최적화

## 8. 완료 기준

1. 루트에서 `npm run dev` 실행 시 스크린샷과 유사한 게임 페이지가 뜬다.
2. 5번 표의 인터랙션이 모두 동작한다.
3. `npm run build`가 에러 없이 통과한다.
